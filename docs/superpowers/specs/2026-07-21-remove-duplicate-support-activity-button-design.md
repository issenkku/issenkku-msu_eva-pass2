# Remove Duplicate Support Activity Button Design

วันที่: 2026-07-21
สถานะ: อนุมัติแนวทางแล้ว รอตรวจทานเอกสารก่อนพัฒนา

## ปัญหา

ในคอลัมน์ `กิจกรรม/โครงการ/งาน` มีปุ่ม `จัดการกิจกรรม/โครงการ` เพิ่มขึ้นมาอีกหนึ่งปุ่ม ขณะที่แต่ละแถวมีปุ่ม `กรอกข้อมูล` หรือ `แก้ไขข้อมูล` ในคอลัมน์ `จัดการ` อยู่แล้ว ปุ่มทั้งสองเปิด Modal เดียวกันและเข้าถึงแบบฟอร์มกิจกรรม คะแนน และหลักฐานชุดเดียวกัน จึงเป็นทางเข้าที่ซ้ำซ้อนและทำให้ตารางดูแน่นขึ้น

## แนวทางที่เลือก

- ลบปุ่ม `จัดการกิจกรรม/โครงการ` และ `แก้ไขกิจกรรม/โครงการ` ออกจากส่วนแสดงชื่อกิจกรรมทั้งในตารางเดสก์ท็อปและการ์ดมือถือ
- ใช้ปุ่ม `กรอกข้อมูล` หรือ `แก้ไขข้อมูล` ในส่วน `จัดการ` เป็นทางเข้าสำหรับแก้ไขข้อมูลของเกณฑ์เพียงจุดเดียว
- ลบ JavaScript event handler ของ `data-support-activity-open` ซึ่งจะไม่มีผู้เรียกใช้อีก
- ภายใน Modal ยังคงส่วนเพิ่ม/แก้ไขกิจกรรม คะแนน หลักฐาน เหตุผล และประวัติไว้เหมือนเดิม

## สิ่งที่ไม่เปลี่ยน

- สิทธิ์ของผู้ถูกประเมินและผู้ประเมินแต่ละ Role
- การเพิ่ม แก้ไข หรือลบกิจกรรมภายใน Modal
- คะแนน หลักฐาน Comment เหตุผล และประวัติการแก้ไข
- Payload, validation, การบันทึกฉบับร่าง และ Flow การยืนยันส่ง
- การแสดงรายการกิจกรรมที่บันทึกแล้วในตารางและการ์ดมือถือ

## การทดสอบ

- เพิ่ม regression test ว่าหน้าแก้ไขไม่แสดง `data-support-activity-open` หรือข้อความบนปุ่มที่ถูกลบ
- ยืนยันว่าปุ่ม `data-support-manage-open` ยังคงอยู่
- ยืนยันว่าฟอร์มกิจกรรมและปุ่มเพิ่ม/ลบกิจกรรมภายใน Modal ยังคงแสดงตาม Role เดิม
- รัน focused PHP tests, JavaScript tests, Blade cache, Vite build และ `git diff --check`

## เกณฑ์สำเร็จ

หน้าเกณฑ์สายสนับสนุนมีทางเข้าแก้ไขข้อมูลต่อรายการเพียงปุ่ม `กรอกข้อมูล` หรือ `แก้ไขข้อมูล` ในส่วน `จัดการ` โดยผู้ใช้ยังสามารถจัดการกิจกรรม คะแนน และหลักฐานทั้งหมดจาก Modal เดิมได้ครบถ้วน
