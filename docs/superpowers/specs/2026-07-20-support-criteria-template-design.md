# Template เกณฑ์สำหรับสายสนับสนุน

วันที่: 20 กรกฎาคม 2569

## เป้าหมาย

เพิ่ม Template เกณฑ์สำหรับสายสนับสนุนในหน้าสร้างและแก้ไขเกณฑ์การประเมิน เพื่อให้แอดมินเตรียมรายการเกณฑ์ไว้ล่วงหน้า โดยไม่เปลี่ยนขั้นตอนกรอกคะแนนของผู้ถูกประเมินในงานรอบนี้

## ขอบเขต

งานนี้ครอบคลุม:

- เพิ่ม Checkbox “เกณฑ์สำหรับสายสนับสนุน” ต่อจาก “เกณฑ์ด้านคุณภาพ”
- เลือก Checkbox แล้วแสดงส่วนฟอร์มสายสนับสนุน และยกเลิกแล้วซ่อนส่วนฟอร์ม
- เลือกเกณฑ์สายสนับสนุนพร้อมเกณฑ์ด้านปริมาณและเกณฑ์ด้านคุณภาพได้
- เพิ่ม ลบ และจัดลำดับรายการเกณฑ์สายสนับสนุนได้หลายรายการภายในรายการประเมินเดียวกัน
- บันทึก โหลด และแก้ไขข้อมูล Template สายสนับสนุน

งานนี้ไม่ครอบคลุม:

- ช่องกรอกคะแนนของผู้ถูกประเมิน
- การคำนวณหรือบันทึกคะแนนถ่วงน้ำหนักจริง
- การแสดงเกณฑ์สายสนับสนุนในหน้าผู้ถูกประเมิน ผู้ประเมิน ผู้บังคับบัญชา หรือหน้าสรุปคะแนน
- การเชื่อมต่อกับ Workload

## รูปแบบหน้าจอ

ในหัวข้อ “ประเภทเกณฑ์” เพิ่ม Checkbox ตัวที่สาม:

```text
☐ เกณฑ์ด้านปริมาณ
☐ เกณฑ์ด้านคุณภาพ
☐ เกณฑ์สำหรับสายสนับสนุน
```

Checkbox ทั้งสามทำงานอย่างอิสระ ส่วนฟอร์มสายสนับสนุนใช้พฤติกรรมแสดง–ซ่อนแบบเดียวกับส่วนปริมาณและคุณภาพ

เมื่อเลือกเกณฑ์สำหรับสายสนับสนุน จะแสดงรายการที่เพิ่มและลบได้ แต่ละรายการมีช่องต่อไปนี้:

1. กิจกรรม/โครงการ/งาน — ข้อความ บังคับกรอก
2. ตัวชี้วัด/เกณฑ์การประเมิน — ข้อความ บังคับกรอก
3. ระดับค่าเป้าหมาย — ตัวเลข บังคับกรอก รองรับทศนิยม และต้องไม่ติดลบ
4. น้ำหนัก — ตัวเลข บังคับกรอก รองรับทศนิยม และต้องอยู่ในช่วงมากกว่า 0 ถึง 100

หน้าฟอร์มแสดงสูตรอ้างอิง:

```text
คะแนนถ่วงน้ำหนัก = น้ำหนัก × คะแนนที่ผู้ถูกประเมินกรอก ÷ 100
```

สูตรนี้ไม่มีช่องกรอกและไม่มีการคำนวณผลลัพธ์ในหน้า Template

## แบบข้อมูล

สร้างตาราง `support_criterias` แยกจากเกณฑ์ปริมาณและคุณภาพ โดยมีข้อมูลหลัก:

- `id`
- `evaluation_list_id` — ความสัมพันธ์กับรายการประเมิน
- `sequence` — ลำดับรายการ
- `activity_name` — กิจกรรม/โครงการ/งาน
- `indicator` — ตัวชี้วัด/เกณฑ์การประเมิน
- `target_value` — ระดับค่าเป้าหมาย
- `weight` — น้ำหนัก
- timestamps

`EvaluationList` มีความสัมพันธ์แบบหนึ่งต่อหลายกับ `SupportCriteria` การลบรายการประเมินต้องลบรายการสายสนับสนุนที่เกี่ยวข้องตามกลไกฐานข้อมูล

## การรับส่งข้อมูล

payload ของรายการประเมินเพิ่ม `support_criterias` เป็น array แต่ละรายการประกอบด้วย id (เมื่อแก้ไข), sequence, activity_name, indicator, target_value และ weight

- หน้า Create ส่งเฉพาะรายการสายสนับสนุนเมื่อเลือก Checkbox
- หน้า Edit โหลดข้อมูลเดิม ติ๊ก Checkbox และแสดงส่วนฟอร์มอัตโนมัติเมื่อมีข้อมูล
- การแก้ไขใช้รูปแบบ sync เดียวกับเกณฑ์ประเภทเดิม: เพิ่มรายการใหม่ อัปเดตรายการเดิม และลบรายการที่ถูกนำออกจาก payload
- การยกเลิก Checkbox ทำให้ไม่ส่งรายการสายสนับสนุน และเมื่อตกลงบันทึกจะลบรายการสายสนับสนุนเดิมของรายการประเมินนั้น

## Validation และข้อผิดพลาด

- เมื่อเลือก Checkbox ต้องมีรายการสายสนับสนุนอย่างน้อยหนึ่งรายการ
- ช่องข้อความต้องไม่เป็นค่าว่าง
- ระดับค่าเป้าหมายต้องเป็นตัวเลขตั้งแต่ 0 ขึ้นไป
- น้ำหนักต้องมากกว่า 0 และไม่เกิน 100
- ไม่บังคับให้ผลรวมน้ำหนักเท่ากับ 100 ในงานรอบนี้ เนื่องจากเป็นการเตรียม Template และยังไม่มีการคำนวณคะแนน
- ฝั่ง browser แจ้งข้อผิดพลาดก่อนส่ง และฝั่ง server ตรวจซ้ำเพื่อป้องกัน payload ที่ไม่ถูกต้อง
- หาก server ปฏิเสธข้อมูล ให้คงฟอร์มไว้และแสดงข้อความที่ระบุช่องหรือรายการที่ผิด

## การทดสอบ

- หน้า Create และ Edit มี Checkbox สายสนับสนุนต่อจากเกณฑ์ด้านคุณภาพ
- Checkbox แสดงและซ่อนส่วนฟอร์มสายสนับสนุนโดยไม่กระทบสองประเภทเดิม
- เพิ่ม ลบ และจัดลำดับรายการสายสนับสนุนได้
- Create บันทึกข้อมูลครบทุกช่องและลำดับถูกต้อง
- Edit โหลด อัปเดต เพิ่ม และลบรายการได้ถูกต้อง
- Validation ปฏิเสธข้อความว่าง ค่าเป้าหมายติดลบ และน้ำหนักนอกช่วง
- เกณฑ์ปริมาณและคุณภาพเดิมยังสร้างและแก้ไขได้เหมือนเดิม

## เกณฑ์สำเร็จ

แอดมินสามารถเลือก “เกณฑ์สำหรับสายสนับสนุน” ในรายการประเมิน เพิ่มข้อมูลกิจกรรม ตัวชี้วัด ระดับค่าเป้าหมาย และน้ำหนัก บันทึก Template แล้วกลับมาแก้ไขข้อมูลเดิมได้ โดยเกณฑ์ด้านปริมาณและคุณภาพไม่ได้รับผลกระทบ และยังไม่มีการเพิ่มพฤติกรรมคะแนนในหน้าของผู้ถูกประเมิน
