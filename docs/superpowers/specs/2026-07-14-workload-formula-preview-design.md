# Workload Formula Preview Design

## Goal

แสดงสูตรภาระงานในรูปแบบที่ผู้ดูแลระบบอ่านเข้าใจได้ โดยแทนรหัสตัวแปร เช่น `num_1` ด้วยชื่อที่กำหนด เช่น `หน่วยกิต` ขณะที่ระบบยังบันทึกและคำนวณจากสูตรรหัสเดิม

## Approaches Considered

1. เพิ่มพรีวิวแบบอ่านอย่างเดียวใต้ช่องสูตรจริง — เลือกแนวทางนี้ เพราะผู้ใช้เห็นทั้งสูตรที่ระบบใช้และสูตรภาษาไทยพร้อมกัน โดยไม่เปลี่ยนสัญญาข้อมูลกับ backend
2. แทนข้อความใน textarea ด้วยชื่อภาษาไทย — ไม่เลือก เพราะชื่อภาษาไทยไม่ใช่ identifier ที่ตัวประเมินสูตรรองรับ และการแปลงกลับอาจกำกวมเมื่อชื่อตัวแปรซ้ำกัน
3. แสดงชื่อไทยเฉพาะเมื่อเอาเมาส์ชี้รหัสตัวแปร — ไม่เลือก เพราะอ่านสูตรทั้งบรรทัดและใช้งานบนอุปกรณ์สัมผัสได้ยากกว่า

## Selected Design

- เพิ่มส่วน `พรีวิวสูตร` ใต้ textarea `สร้างการคำนวณ` ภายใน workload sub-card แต่ละใบ
- สูตรจริงใน textarea และ payload `formula_logic` ไม่เปลี่ยนแปลง
- สร้างพรีวิวโดยแทน identifier แบบทั้งคำเท่านั้น เพื่อไม่ให้ `num_1` ไปเปลี่ยนบางส่วนของ `num_10`
- ตัวแปรที่ผู้ใช้สร้างใช้ mapping จาก `.formula-value` ไปยัง `.formula-item-label`
- ตัวแปรในระบบใช้ชื่อไทยดังนี้:
  - `item_star` → `ค่าภารงาน`
  - `credits` → `หน่วยกิตรวม`
  - `lecture_credits` → `หน่วยกิตบรรยาย`
  - `lab_credits` → `หน่วยกิตปฏิบัติ`
  - `self_study_credits` → `หน่วยกิตศึกษาด้วยตนเอง`
- เปลี่ยนเครื่องหมาย `*` เป็น `×` และ `/` เป็น `÷` เฉพาะข้อความพรีวิว
- identifier ที่ไม่มี mapping ยังคงแสดงเป็นรหัสเดิม เพื่อให้ผู้ใช้เห็นข้อผิดพลาดและแก้สูตรได้
- เมื่อสูตรว่าง พรีวิวแสดงข้อความ `พรีวิวจะแสดงเมื่อระบุสูตรการคำนวณ`

## Update Events

พรีวิวอัปเดตเมื่อ:

- พิมพ์หรือวางข้อความใน textarea
- คลิกเครื่องหมาย ฟังก์ชัน หรือตัวแปรเพื่อแทรกลงในสูตร
- เพิ่ม แก้ไข หรือลบตัวแปร
- โหลดข้อมูลสูตรเดิมเข้าสู่ sub-card

## Accessibility

- ใช้ข้อความจริงใน DOM ไม่ใช้ placeholder เพียงอย่างเดียว
- พรีวิวมี label ที่มองเห็นได้ และใช้ `aria-live="polite"` เพื่อประกาศการเปลี่ยนแปลงโดยไม่รบกวนผู้ใช้
- พรีวิวไม่รับ focus เพราะไม่มีการโต้ตอบ

## Testing

- เพิ่ม unit-level coverage สำหรับการแทน identifier แบบทั้งคำ การแปลง built-in variables และการคง identifier ที่ไม่รู้จัก
- เพิ่ม view-level assertion ว่ามีโครงสร้างพรีวิวและ accessibility attributes
- รัน feature tests ที่เกี่ยวข้องกับ workload configuration และ build frontend เพื่อจับ syntax หรือ bundling regressions

## Scope

งานนี้เปลี่ยนเฉพาะหน้าตั้งค่าภาระงาน ไม่เปลี่ยน evaluator, validation, schema ฐานข้อมูล หรือหน้าสรุปผลอื่น
