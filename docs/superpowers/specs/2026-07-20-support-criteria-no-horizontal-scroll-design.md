# Support Criteria Table Without Horizontal Scrolling Design

วันที่: 2026-07-20
สถานะ: อนุมัติแนวทางแล้ว รอตรวจทานเอกสารก่อนพัฒนา

## ปัญหา

ตารางเกณฑ์สายสนับสนุนกำหนดความกว้างขั้นต่ำ `min-w-[1180px]` และอยู่ใน container ที่ใช้ `overflow-x-auto` จึงเกิดแถบเลื่อนซ้าย–ขวาและบางคอลัมน์อาจหลุดออกจากมุมมอง

## เป้าหมาย

- หน้าเกณฑ์สายสนับสนุนต้องไม่มีการเลื่อนแนวนอนในทุกขนาดหน้าจอ
- จอกว้างตั้งแต่ 1024px แสดงตารางครบทุกคอลัมน์ภายในกรอบ
- จอแคบกว่า 1024px ใช้รูปแบบการ์ดเดิมเพื่อให้อ่านข้อมูลได้ครบโดยไม่บีบคอลัมน์

## แนวทางที่เลือก

ใช้ตารางแบบความกว้างคงที่ตามสัดส่วนเฉพาะเมื่อ viewport กว้างตั้งแต่ 1024px และสลับเป็นการ์ดเมื่อแคบกว่านั้น แนวทางนี้แสดงข้อมูลครบโดยไม่ต้องซ่อนคอลัมน์หรือฝืนใช้ตารางบนจอแคบ

## การจัดวางตาราง

- ลบ `overflow-x-auto` จาก container ของตาราง
- ลบ `min-w-[1180px]` และ `min-w-*` ที่กำหนดให้แต่ละคอลัมน์
- ใช้ `w-full table-fixed` เพื่อให้ตารางไม่กว้างเกิน container
- แบ่งความกว้างแต่ละคอลัมน์ตามสัดส่วน โดยให้กิจกรรมและตัวชี้วัดมีพื้นที่มากที่สุด ส่วนคอลัมน์ค่าต่าง ๆ และปุ่มใช้พื้นที่ตามความจำเป็น
- อนุญาตให้ข้อความยาวตัดขึ้นบรรทัดใหม่ภายในเซลล์ และป้องกันข้อความที่ไม่มีช่องว่างดันตารางให้ล้นกรอบ

## Responsive

- ตารางใช้ `hidden lg:table` จึงแสดงตั้งแต่ breakpoint `lg` (1024px) ขึ้นไป
- การ์ดใช้ `lg:hidden` จึงแสดงเฉพาะเมื่อจอแคบกว่า 1024px
- ห้ามมี container ที่เปิด horizontal scrolling ครอบตาราง

## สิ่งที่ไม่เปลี่ยน

- ลำดับและข้อมูลของคอลัมน์
- การเปิด Modal จากคอลัมน์จัดการหรือหลักฐาน
- การกรอกคะแนน หลักฐาน เหตุผล ประวัติการแก้ไข และ comment ของแต่ละ Role
- payload, validation, การคำนวณ และ Flow การบันทึก/ยืนยันส่ง
- wrapper หลัก `max-w-7xl` และขนาด Modal

## การทดสอบ

- ตรวจว่า container ของตารางไม่มี `overflow-x-auto`
- ตรวจว่าตารางไม่มี `min-w-[1180px]` หรือความกว้างขั้นต่ำรายคอลัมน์
- ตรวจว่าตารางใช้ `w-full table-fixed` และแสดงตั้งแต่ `lg`
- ตรวจว่าการ์ดแสดงต่ำกว่า `lg`
- ตรวจทั้งโหมดแก้ไขและโหมดอ่านอย่างเดียวว่ายังแสดงคอลัมน์ตามสิทธิ์และเปิด Modal ได้เหมือนเดิม
- รัน focused tests, full PHP test suite, Blade cache, Vite build และ `git diff --check`

## เกณฑ์สำเร็จ

ทุกขนาดหน้าจอไม่แสดงแถบเลื่อนแนวนอนสำหรับเกณฑ์สายสนับสนุน จอกว้างแสดงตารางครบโดยไม่ล้นกรอบ จอที่แคบกว่า 1024px แสดงการ์ดแทน และการกรอก/บันทึกข้อมูลทำงานตาม Flow เดิม
