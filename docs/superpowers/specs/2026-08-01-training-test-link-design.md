# Training Test Link Design

## Goal

เพิ่มลิงก์เข้าสู่ระบบทดสอบและคำชี้แจงการนำระบบขึ้นใช้งานจริงในสไลด์ฝึกปฏิบัติของชุดอบรมสายวิชาการและสายสนับสนุน

## Content

- ลิงก์ทดสอบ: `http://149.28.142.186/login`
- คำชี้แจง: “ลิงก์นี้ใช้สำหรับทดสอบระบบ เมื่อทุกท่านตรวจสอบแล้วและไม่มีประเด็นที่ต้องปรับแก้เพิ่มเติม ทีมงานจะนำระบบไปติดตั้งบนเซิร์ฟเวอร์ของคณะทันทีครับ”
- บทพูดวิทยากรต้องแจ้งให้ผู้เข้าอบรมเปิดลิงก์และเข้าสู่ระบบด้วยบัญชีที่เตรียมไว้

## Placement

- แก้เฉพาะสไลด์ 17 ของทั้งสองชุด
- วางคำชี้แจงใต้หัวข้อหลัก
- วาง URL เป็นข้อความเด่นสีน้ำเงินและขีดเส้นใต้
- เลื่อนรายการฝึกปฏิบัติลงเล็กน้อยโดยคงกล่องเกณฑ์ผ่านและส่วนท้ายเดิม

## Verification

- URL และคำชี้แจงปรากฏครบทั้งสองชุด
- โน้ตสไลด์ 17 มี URL และคำชี้แจง
- ไม่มีข้อความซ้อน ตัด หรือวัตถุหลุดขอบ
- สไลด์อื่นทั้ง 17 หน้าต่อชุดไม่เปลี่ยน
