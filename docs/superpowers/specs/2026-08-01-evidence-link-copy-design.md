# Evidence Link Copy Design

## Goal

แก้ข้อความเรื่องหลักฐานในชุดอบรมให้ตรงกับระบบจริง ซึ่งรับลิงก์ HTTP/HTTPS และไม่มีช่องอัปโหลดหรือตั้งชื่อไฟล์

## Approved copy

- หัวข้อ: `ตรวจสอบได้ชัดเจน`
- คำอธิบาย: `เปิดลิงก์แล้วรู้ว่าเป็นหลักฐานของรายการใด`

## Scope

- แก้สไลด์ 11 ของสายวิชาการ
- แก้สไลด์ 12 ของสายสนับสนุน
- แก้บทพูดของสองหน้านี้ไม่ให้กล่าวถึงการตั้งชื่อไฟล์หรือเอกสาร
- คงสไลด์และโน้ตหน้าอื่นทั้งหมด

## Verification

- ข้อความใหม่ปรากฏครบทั้งสองชุด
- ไม่พบข้อความ `ตั้งชื่อไฟล์` หรือ `ชื่อเอกสาร` ในบทพูดของหน้าหลักฐาน
- ไม่มีข้อความตัด ซ้อน หรือวัตถุหลุดขอบ
