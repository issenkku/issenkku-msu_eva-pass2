# Presentation-First Continuous Demo Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** เปลี่ยน PowerPoint อบรมทั้งสองชุดให้นำเสนอสไลด์ 1–16 ก่อน แล้วสาธิตระบบต่อเนื่องครั้งเดียว ก่อนกลับมาสไลด์ 17–18

**Architecture:** ปรับเฉพาะอาร์เรย์ Speaker Notes ในสคริปต์สร้าง PowerPoint โดยลบป้ายและขั้นตอนสาธิตที่กระจายอยู่หลายหน้า แล้วประกอบสคริปต์สาธิตต่อเนื่องไว้ใน Notes สไลด์ 16 จากนั้นสร้างและตรวจ PPTX ใหม่ด้วย `@oai/artifact-tool`

**Tech Stack:** JavaScript ES modules, `@oai/artifact-tool`, PowerPoint COM, PowerShell, OOXML/ZIP inspection

## Global Constraints

- สไลด์ 1–16 เป็นช่วงนำเสนอ ไม่เปิดระบบระหว่างสไลด์
- จบสไลด์ 16 จึงเริ่มสาธิตต่อเนื่องครั้งเดียว
- สไลด์ 17 ให้ทดลองและหยุดที่บันทึกร่าง
- สไลด์ 18 สรุป แก้ปัญหา และถาม–ตอบ
- รักษา 18 สไลด์ต่อชุด รูปแบบ สี ชื่อเต็มระบบ และข้อความที่มองเห็นล่าสุด
- Notes ทุกหน้าต้องมี `[พูด]` และ `[Sources]`

Expected:

```text

slides 1–15 containing [สาธิต] = 0
slides 1–15 containing [กลับมานำเสนอ] = 0
```

### Task 2: รวมสคริปต์สาธิตต่อเนื่องไว้ในสไลด์ 16

**Files:**
- Modify: `C:/Users/pisut/AppData/Local/Temp/codex-presentations/training-facilitator-2026-07-30/tmp/build-facilitator-decks.mjs`

**Interfaces:**
- Consumes: รายละเอียดสาธิตเดิมจากสไลด์ 7–16
- Produces: Notes สไลด์ 16 ที่ควบคุมการสาธิตทั้งหมด

- [ ] **Step 1: เพิ่มประโยคเริ่มสาธิต**

ใช้ข้อความ:

```text
[เริ่มสาธิตระบบ] ต่อไปผมจะสาธิตขั้นตอนทั้งหมดบนระบบให้ดูตั้งแต่เริ่มต้นจนงานเสร็จครับ ทุกท่านยังไม่ต้องกดตาม ให้สังเกตลำดับการทำงานก่อน
```

- [ ] **Step 2: เพิ่มรายการสาธิตต่อเนื่อง**

ใช้ป้าย `[สาธิตต่อเนื่อง]` หนึ่งครั้งและรายการ 10 ขั้นตอน:

```text
1. เปิดแดชบอร์ดและรายการที่ได้รับมอบหมาย
2. กรอกข้อมูลหรือกิจกรรม
3. ตรวจคะแนนที่ระบบคำนวณ
4. แนบและเปิดหลักฐาน
5. บันทึกร่าง
6. ตรวจความพร้อมและส่งแบบประเมิน
7. เปิดมุมผู้ประเมิน
8. ตรวจข้อมูล ให้ผล และส่งต่อ
9. เปิดบัญชีผู้ประเมินลำดับสุดท้าย
10. ยืนยันผลจนสถานะเป็น ประเมินเสร็จสิ้น (Completed)
```

- [ ] **Step 3: เพิ่มคำสั่งกลับมานำเสนอ**

ใช้ข้อความ:

```text
[กลับมานำเสนอ] เมื่อเห็นขั้นตอนทั้งหมดแล้ว ต่อไปทุกท่านจะได้ทดลองทำด้วยบัญชีที่เตรียมไว้ครับ
```

- [ ] **Step 4: ตรวจสไลด์ 16**

ทั้งสองชุดต้องมี `[เริ่มสาธิตระบบ]`, `[สาธิตต่อเนื่อง]` และ `[กลับมานำเสนอ]` อย่างละหนึ่งครั้ง และมีหมายเลขขั้นตอน 1–10 ครบ
