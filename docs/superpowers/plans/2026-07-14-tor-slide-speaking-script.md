# TOR Slide Speaking Script Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** เพิ่มสคริปต์ภาษาไทยความยาวประมาณ 1–2 นาทีสำหรับสไลด์ “ฟีเจอร์เทียบกับข้อกำหนด TOR” ลงในคู่มือผู้นำประชุม

**Architecture:** เป็นการแก้เอกสารเพียงไฟล์เดียว โดยเพิ่มสคริปต์แบบอ่านตามหลังรายการสถานะทั้งสามกลุ่มและก่อนประโยคป้องกันการรับปากเกินจริง สคริปต์ไล่จากคอลัมน์ซ้ายไปขวา อธิบายความหมายของเครื่องหมายถูก และแยกชุดทดสอบเฉพาะฟังก์ชันออกจาก UAT อย่างเป็นทางการ

**Tech Stack:** Markdown, PowerShell และ ripgrep

## Global Constraints

- ใช้ภาษาไทยแบบภาษาพูดที่อ่านออกเสียงได้เป็นธรรมชาติภายในประมาณ 1–2 นาที
- อธิบายจากคอลัมน์ซ้ายไปขวาตามลำดับในสไลด์
- ระบุว่าเครื่องหมายถูกเป็นสัญลักษณ์นำหน้ารายการ ไม่ได้หมายถึงผ่าน UAT แล้ว
- ระบุว่าชุดทดสอบในคอลัมน์กลางรองรับเฉพาะบางฟังก์ชันและยังไม่ใช่ผลทดสอบรับรองระบบทั้งหมด
- ไม่กล่าวว่าการเชื่อมต่อ Phase 1 รายงาน คู่มือ การอบรม การติดตั้ง หรือ UAT อย่างเป็นทางการเสร็จแล้ว
- ไม่แก้ไฟล์ PowerPoint หรือไฟล์อื่นนอกขอบเขตงานนี้

```markdown
### สคริปต์นำเสนอสไลด์นี้ — ประมาณ 1–2 นาที

> สไลด์นี้เป็นการเทียบฟีเจอร์ของระบบกับข้อกำหนดใน TOR โดยแบ่งเป็นสามกลุ่มตามสถานะปัจจุบันครับ เครื่องหมายถูกหน้ารายการในหน้านี้ใช้เป็นสัญลักษณ์นำหน้ารายการเท่านั้น ไม่ได้หมายความว่ารายการนั้นผ่าน UAT แล้วครับ
>
> กลุ่มแรกทางซ้ายสีเขียวคือส่วนที่พร้อมสาธิตในวันนี้ ได้แก่ การที่ Admin กำหนดแบบฟอร์มและข้อมูลที่ต้องการเก็บ การกำหนดสูตรพร้อมพรีวิวที่อ่านง่าย การบันทึกข้อมูลภาระงานของผู้รับการประเมิน และการคำนวณคะแนนจากข้อมูลที่บันทึกครับ
>
> กลุ่มตรงกลางสีฟ้าเป็นส่วนสนับสนุนที่มีอยู่ในระบบหรือมีชุดทดสอบเฉพาะฟังก์ชันรองรับ เช่น การแนบลิงก์หลักฐาน การแยกสิทธิ์ตามบทบาท การเก็บประวัติการแก้ไข รวมถึงการทดสอบด้านประสิทธิภาพและการเข้าสู่ระบบ อย่างไรก็ตาม ส่วนนี้ยังไม่ใช่ผลการทดสอบรับรองระบบทั้งหมดครับ
>
> ส่วนกลุ่มทางขวาสีส้มเป็นงานที่อยู่ในแผนหรือยังต้องยืนยันรายละเอียดร่วมกัน ได้แก่ คู่มือ การอบรม การติดตั้งและดูแลระบบ รูปแบบรายงาน PDF หรือ Excel และการทำ UAT อย่างเป็นทางการครับ
>
> ดังนั้น วันนี้ผมจะเน้นสาธิตส่วนที่พร้อมใช้งานให้เห็นก่อน และขอรวบรวมข้อสรุปของส่วนที่ยังต้องหารือ เพื่อนำไปดำเนินการตามแผนต่อไปครับ
```
