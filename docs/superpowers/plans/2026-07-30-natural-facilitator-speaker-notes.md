# Natural Facilitator Speaker Notes Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** ปรับ Speaker Notes ของสไลด์อบรม MSU EVA ทั้งสองชุดให้เป็นภาษาพูดสุภาพและเป็นธรรมชาติ โดยไม่เปลี่ยนเนื้อหาที่มองเห็นบนสไลด์

**Architecture:** ใช้สคริปต์สร้างงานนำเสนอเดิมเป็นแหล่งข้อมูลหลัก แก้เฉพาะข้อความในอาร์เรย์ `academicScripts` และ `supportScripts` แล้วสร้างไฟล์ PPTX ใหม่ด้วย `@oai/artifact-tool` จากนั้นตรวจโครงสร้าง Notes และเปิดไฟล์ผ่าน PowerPoint เพื่อยืนยันว่าไฟล์สมบูรณ์

**Tech Stack:** JavaScript ES modules, `@oai/artifact-tool`, PowerPoint COM, PowerShell, OOXML/ZIP inspection

## Global Constraints

- สายวิชาการและสายสนับสนุนต้องมีชุดละ 18 สไลด์และ 18 Speaker Notes
- Notes ทุกหน้าต้องมี `[พูด]` และ `[Sources]`
- หน้าที่สาธิตต้องรักษา `[สาธิต]` ไว้
- ใช้โทนสุภาพเป็นธรรมชาติ เช่น “ใช่ครับ”, “ทีนี้…”, “ต่อไปเรามาดู…” ตามบริบท
- ไม่ใช้คำติดปากเดียวกันขึ้นต้นทุกหน้า
- ไม่แก้ข้อความ รูปแบบ สี หรือลำดับของสไลด์ที่ผู้ชมมองเห็น
- Admin ยังคงเป็นผู้กำหนดรอบประเมิน การมอบหมาย และลำดับผู้ประเมิน
- ผู้เข้าอบรมไม่ต้องสร้างหรือเลือกรอบประเมินเอง

### Task 1: ปรับบทพูดชุดสายวิชาการ

**Files:**
- Modify: `C:/Users/pisut/AppData/Local/Temp/codex-presentations/training-facilitator-2026-07-30/tmp/build-facilitator-decks.mjs`

**Interfaces:**
- Consumes: อาร์เรย์ `academicScripts` จำนวน 18 รายการ
- Produces: Speaker Notes สายวิชาการที่พร้อมส่งให้ฟังก์ชันสร้างสไลด์เดิม

- [ ] **Step 1: ตรวจข้อความและป้ายกำกับเดิม**

ค้นหา `academicScripts` และยืนยันว่ามี 18 รายการ แต่ละรายการมี `[พูด]` และ `[Sources]` หลังประกอบ Notes

- [ ] **Step 2: เขียนบทพูดใหม่ครบ 18 หน้า**

ปรับแต่ละรายการให้มีโครงดังนี้:

```text
[พูด] <ประโยคเชื่อมจากหน้าก่อน> <อธิบายสาระด้วยภาษาพูด>
<ประโยคเน้นสิ่งที่ต้องจำหรือทำ> <ประโยคส่งไปหน้าถัดไป>
```

หน้าสาธิตใช้รูปแบบ:

```text
[พูด] เดี๋ยวผมทำให้ดูก่อนครับ ทุกท่านยังไม่ต้องกดตามนะครับ ให้สังเกต...
[สาธิต] <การสาธิตเดิม>
```

รักษาคำสำคัญ `บันทึกร่าง`, `ส่งแบบประเมิน`, `ประเมินเสร็จสิ้น (Completed)` และข้อเท็จจริงเรื่อง Admin ตามฉบับเดิม

- [ ] **Step 3: ตรวจความเป็นธรรมชาติด้วยสคริปต์**

นับข้อความที่มีคำเชื่อมจากชุดคำต่อไปนี้ และต้องพบครบทั้ง 18 รายการ:

```js
const conversationalPattern =
  /(ครับ|ทีนี้|ต่อไป|ตรงนี้|เดี๋ยวผม|เรามาดู|ทุกท่าน|ลองสังเกต)/;
```

ตรวจเพิ่มเติมว่าไม่มีคำว่า `ใช่ครับ` ขึ้นต้นติดต่อกันเกิน 2 หน้า

- [ ] **Step 4: บันทึกจุดตรวจ**

ยืนยันว่าเนื้อหาสายวิชาการยังกล่าวถึงรายวิชา ภาระงาน ผลงานเชิงปริมาณ ผลงานเชิงคุณภาพ และหลักฐานครบถ้วน

### Task 2: ปรับบทพูดชุดสายสนับสนุน

- Produces: Speaker Notes สายสนับสนุนที่พร้อมส่งให้ฟังก์ชันสร้างสไลด์เดิม

ค้นหา `supportScripts` และยืนยันว่ามี 18 รายการ แต่ละรายการมี `[พูด]` และ `[Sources]` หลังประกอบ Notes

- [ ] **Step 2: เขียนบทพูดใหม่ครบ 18 หน้า**

ใช้บุคลิกวิทยากรเดียวกับช่วงเช้า แต่เปิดช่วงบ่ายด้วยการรับผู้เข้าอบรมกลุ่มใหม่ และใช้ตัวอย่างที่สัมพันธ์กับกิจกรรม เป้าหมาย ผลการดำเนินงาน คะแนนถ่วงน้ำหนัก และหลักฐาน

```text
โอเคครับ ทีนี้เรามาดู...
ตรงนี้ขอเน้นนิดหนึ่งครับ...
เมื่อเห็นภาพรวมแล้ว ต่อไปเราจะ...
เดี๋ยวผมลองคำนวณให้ดูก่อนครับ...
```

- [ ] **Step 4: ตรวจความเป็นธรรมชาติและสาระ**

ใช้ `conversationalPattern` เดียวกับ Task 1 และยืนยันว่าเนื้อหายังคงครอบคลุมกิจกรรม เป้าหมาย ผลการดำเนินงาน สูตรคะแนนถ่วงน้ำหนัก หลักฐาน และการส่งงานตามลำดับผู้ประเมิน
