# Plain-Language Demo Transitions Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** ทำให้บทพูดเข้าใจง่ายขึ้น และระบุชัดเจนว่าวิทยากรต้องเปลี่ยนจากสไลด์ไปสาธิตระบบและกลับมานำเสนอเมื่อใด

**Architecture:** แก้เฉพาะอาร์เรย์บทพูดที่ใช้งานจริงในสคริปต์สร้าง PowerPoint เดิม โดยใช้ป้ายกำกับมาตรฐานสามแบบ ได้แก่ `[เปลี่ยนไปสาธิตระบบ]`, `[สาธิต]` และ `[กลับมานำเสนอ]` แล้วสร้างและตรวจ PPTX ทั้งสองชุดใหม่

**Tech Stack:** JavaScript ES modules, `@oai/artifact-tool`, PowerPoint COM, PowerShell, OOXML/ZIP inspection

## Global Constraints

- ใช้ประโยคตรงและบอกชัดว่าใครต้องทำอะไร
- ไม่ใช้ข้อความ “เป็นเจ้าของความครบถ้วนของข้อมูล”
- สไลด์ 1–6 เป็นช่วงอธิบายภาพรวม
- จบสไลด์ 6 ต้องบอกว่าตั้งแต่สไลด์ถัดไปจะเริ่มสาธิต
- สไลด์ 7–16 สาธิตตามหัวข้อ ไม่รอจนจบสไลด์ทั้งหมด
- สไลด์ 17 ให้ผู้เข้าอบรมทดลองและหยุดที่บันทึกร่าง
- สไลด์ 18 สรุป แก้ปัญหา และถาม–ตอบ
- ไม่เปลี่ยนข้อเท็จจริงเรื่อง Admin รอบประเมิน การมอบหมาย และลำดับผู้ประเมิน
