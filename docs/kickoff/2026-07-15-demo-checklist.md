# เช็กลิสต์ก่อนประชุมและสาธิตระบบ

## คืนก่อนประชุม

- [ ] อ่านสคริปต์เปิดและปิดออกเสียงอย่างละ 2 รอบ
- [ ] เปิด PowerPoint และตรวจว่าตัวอักษรไทยไม่ล้นหรือกลายเป็นสี่เหลี่ยม
- [ ] เตรียมบัญชีทดสอบ Admin และ Evaluatee ที่ไม่มีข้อมูลส่วนบุคคลจริง
- [ ] เตรียมข้อมูลตัวอย่างหนึ่ง Workflow ตั้งแต่แบบฟอร์มถึงคะแนน
- [ ] ตรวจว่ารายการตัวอย่างมี Field สูตร ลิงก์หลักฐานทดสอบ และคะแนน
- [ ] จด URL ของหน้า Workload Config และหน้า Evaluatee ไว้ในโพยส่วนตัว
- [ ] เปิด `2026-07-15-tor-system-matrix.md` และ `2026-07-15-facilitator-runbook.md` ไว้ในเครื่อง
- [ ] เตรียมผู้ช่วยจด Minutes หรือเปิดแบบบันทึกให้พร้อม
- [ ] เตรียมอินเทอร์เน็ตสำรองหรือ Hotspot
- [ ] ปิด Notification ที่อาจแสดงข้อมูลส่วนตัวระหว่างแชร์หน้าจอ

## เวลา 08:15 น. — เข้าห้องและตรวจอุปกรณ์

- [ ] เข้า Microsoft Teams
- [ ] ตรวจไมโครโฟน ลำโพง และกล้อง
- [ ] ทดลองแชร์เฉพาะหน้าต่าง PowerPoint หรือเบราว์เซอร์
- [ ] ตั้ง browser zoom ให้ตัวอักษรอ่านได้ชัด
- [ ] ตรวจว่าบัญชี Admin และ Evaluatee ยังเข้าสู่ระบบได้
- [ ] ปิดแท็บ อีเมล แชต และไฟล์ที่ไม่เกี่ยวข้อง
- [ ] วางไฟล์ PowerPoint, runbook และ minutes template บน Taskbar

## เวลา 08:30 น. — พร้อมเริ่มตามเวลาปฏิทิน

- [ ] เปิดสไลด์หน้าแรกแบบเต็มจอ
- [ ] เปิดแท็บเดโมตามลำดับ Admin → Workload Config → Evaluatee → รายการตัวอย่าง
- [ ] ยืนยันกับอาจารย์ว่าเริ่มประชุมทันทีหรือรอเวลา 08:45 น.
- [ ] แจ้งผู้จดบันทึกให้เริ่มบันทึกเวลาและรายชื่อผู้เข้าร่วม

## เวลา 08:45 น. — เวลาในข้อความนัดหมาย

- [ ] หากยังไม่เริ่ม ให้ขออนุญาตเปิดประชุม
- [ ] หากเริ่มแล้ว ให้ดำเนินวาระต่อโดยไม่ย้อนเนื้อหา ยกเว้นผู้มีอำนาจขอให้สรุป

## แท็บเดโมที่ต้องเปิด

1. PowerPoint หน้าแรก
2. Workload Config พร้อมเกณฑ์ตัวอย่าง
3. มุมมอง Evaluatee พร้อมรายการตัวอย่าง
4. หน้า Audit Log หรือผลทดสอบที่ใช้เป็นหลักฐาน
5. ตารางเทียบ TOR กับระบบ
6. แบบบันทึก Minutes

## ข้อห้ามระหว่างเดโม

- [ ] ไม่ลบข้อมูลจริง
- [ ] ไม่เปลี่ยนสูตรจริงโดยไม่ได้รับอนุญาต
- [ ] ไม่เปิดลิงก์หลักฐานที่มีข้อมูลส่วนบุคคล
- [ ] ไม่กรอกรหัสผ่านขณะแชร์หน้าจอ หากหลีกเลี่ยงได้
- [ ] ไม่กล่าวว่า Phase 1 เชื่อมต่อสมบูรณ์หากยังไม่ได้ทดสอบร่วมกัน
- [ ] ไม่รับปากวันส่งมอบใหม่โดยไม่มีผู้มีอำนาจยืนยัน

## แผนสำรองเมื่อระบบมีปัญหา

- ระบบ Login ไม่ได้: ใช้ PowerPoint และตาราง TOR ต่อ แล้วบันทึกนัดเดโมเพิ่ม
- หน้า Workload Config เปิดไม่ได้: อธิบายจาก Workflow และหลักฐาน Route/Test
- อินเทอร์เน็ตขัดข้อง: ใช้ไฟล์ในเครื่องและโทรเข้าประชุมจากอุปกรณ์สำรอง
- คะแนนตัวอย่างไม่ตรง: หยุดเดโมส่วนนั้น บันทึกเป็น Action Item และไม่แก้สดต่อหน้าที่ประชุม
- เวลาเหลือน้อย: ใช้แผนย่อ 30 นาทีและรักษาช่วงสรุปมติไว้

## แผนย่อ 30 นาที

- 3 นาที — เปิดประชุมและแจ้งผลลัพธ์
- 5 นาที — เป้าหมายและขอบเขต
- 10 นาที — เดโม Workflow หลัก
- 5 นาที — แผน 90 วัน
- 7 นาที — มติ ผู้รับผิดชอบ และกำหนดส่ง

## หลังประชุมทันที

- [ ] อ่านทวนมติและ Action Item ก่อนทุกคนออกจากห้อง
- [ ] บันทึกไฟล์ Minutes ด้วยวันที่และเวลาประชุม
- [ ] ส่งสรุปให้ผู้เข้าร่วมตรวจสอบในช่องทางที่ตกลงกัน
- [ ] แยกคำขอใหม่ออกจากข้อกำหนดเดิมก่อนนำเข้าสู่แผนพัฒนา
- [ ] นัดหมายผู้รับผิดชอบเรื่องสูตร Integration ข้อมูลทดสอบ และ UAT
