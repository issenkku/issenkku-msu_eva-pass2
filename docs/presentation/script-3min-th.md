สคริปต์พูด 3 นาที — [SYSTEM_NAME]

เกริ่น (20 วินาที)
วันนี้ขอแนะนำระบบประเมินผลบุคลากร [SYSTEM_NAME] ซึ่งออกแบบให้ครอบคลุมตั้งแต่การบริหารข้อมูลพื้นฐาน การมอบหมายงานประเมิน ไปจนถึงการดูรายงานและส่งออกผลลัพธ์ในไฟล์ Excel ภายในที่เดียว

สิทธิ์และการเข้าใช้งาน (25 วินาที)
ผู้ใช้ล็อกอินและระบบจะพาไปหน้าเหมาะกับบทบาททันที เช่น ผู้ดูแล (Admin), ผู้จัดการ (Manager), ผู้อำนวยการ (Director), ผู้ประเมิน (Evaluator), ผู้ถูกประเมิน (Evaluatee) เพื่อให้การทำงานเป็นไปตามสิทธิ์อย่างปลอดภัย

Dashboard และภาพรวม (35 วินาที)
หน้า Dashboard แสดงจำนวนงานในแต่ละสถานะ เช่น Assigned, Draft, In-progress, Completed พร้อมค่าเฉลี่ยคะแนน กราฟภาพรวม และตัวกรองตามคำค้น ปี ช่วงเวลา และแผนก ช่วยให้ผู้บริหารติดตามความคืบหน้าได้อย่างรวดเร็ว

การบริหารข้อมูลหลัก (35 วินาที)
ผู้ดูแลสามารถจัดการแผนก (Departments) ตำแหน่ง (Positions) การตั้งค่าเว็บไซต์ (Settings) และบทบาท/สิทธิ์ (Roles & Permissions) รวมทั้งตรวจสอบ Activity Log เพื่อความโปร่งใสและตรวจสอบย้อนหลังได้

ผู้ใช้และการนำเข้า (25 วินาที)
ในเมนู Users สามารถสร้าง แก้ไข ลบผู้ใช้ และ Import รายชื่อจากเทมเพลต เพื่อเตรียมระบบให้พร้อมใช้งานได้อย่างรวดเร็ว

รอบประเมินและเวิร์กโฟลว์คะแนน (30 วินาที)
ผู้ดูแลกำหนดรอบ/ช่วงเวลาใน Assignment Data และมอบหมายงานให้ผู้ประเมิน กรอกคะแนนเชิงปริมาณ+เชิงคุณภาพ ระบบคำนวณคะแนนรวมอัตโนมัติ และรองรับการกำหนดเกณฑ์/สัดส่วนคุณภาพตามรายงาน

รายงานและการส่งออก (20 วินาที)
สามารถดูรายงานภาพรวมและรายบุคคล พร้อมส่งออกเป็น Excel ได้ทั้งแบบรวมทั้งระบบและแบบรายงานเดี่ยว รองรับการใช้งานจริงของฝ่าย HR และผู้บริหาร

สรุป (20 วินาที)
[SYSTEM_NAME] ช่วยลดเวลาการทำงานซ้ำซ้อน เพิ่มความโปร่งใส ตรวจสอบย้อนกลับได้ และทำให้ผู้บริหารเห็นผลลัพธ์เชิงภาพ เพื่อนำไปตัดสินใจได้ทันที
