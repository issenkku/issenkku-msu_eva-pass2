# Demo Runbook — [SYSTEM_NAME]

ระยะเวลาเดโมแนะนำ: 6–8 นาที (พูด 3 + คลิก 3–4 + Q&A 1–2)

ลำดับคลิก (พร้อมจุดพูด)
- Login (Admin)
  - จุดพูด: ระบบพาเข้าหน้าตามบทบาทอัตโนมัติ (Role-based routing)

- Dashboard
  - ชี้: ตัวเลขสถานะ (Assigned/Draft/In-progress/Completed), ค่าเฉลี่ยคะแนน, กราฟ, ตัวกรองช่วงเวลา/แผนก
  - จุดพูด: ผู้บริหารเห็นภาพรวมได้ทันที และ Filter ได้ตามเงื่อนไข

- Departments / Positions
  - คลิกเพิ่ม-แก้ไขรายการสั้นๆ (ไม่ต้องบันทึกจริง หากเป็นระบบโปรดักชัน)
  - จุดพูด: โครงสร้างองค์กรที่เป็นมาตรฐาน หนุนเวิร์กโฟลว์ประเมิน

- Users
  - ชี้ปุ่ม Download Template และ Import รายชื่อ (แสดงไฟล์ตัวอย่างถ้ามี)
  - จุดพูด: ตั้งต้นระบบเร็ว นำเข้าผู้ใช้จำนวนมากได้
  
- Assignment Data
  - สร้างรอบประเมินใหม่ (ตั้งชื่อและช่วงเวลา) แล้วบันทึก
  - จุดพูด: นิยามรอบงานชัดเจน คุมทีมและช่วงเวลา
- Quality Scores
  - แสดงการกำหนดเกณฑ์/สัดส่วน และการดึงเกณฑ์ตามรายงาน
  - จุดพูด: คะแนนคุณภาพปรับได้ตามนโยบาย และคำนวณอัตโนมัติ
- สลับบทบาทเป็น Evaluator
  - เปิดรายการที่ได้รับมอบหมาย กรอกคะแนนตัวอย่าง 1 รายการ แล้วบันทึก
  - จุดพูด: เวิร์กโฟลว์เรียบง่าย ใช้งานได้จริงในภาคสนาม
- Reports / Export
  - เปิดรายงานรวม กด Export Excel และชี้ทางลัด export รายบุคคล
  - จุดพูด: พร้อมใช้งานข้อมูลต่อทันทีในรูปแบบที่คุ้นเคย
