# Presentation Kit (Thai)

ไฟล์ชุดนี้คือสคริปต์และเอกสารประกอบสำหรับเดโม/นำเสนอโครงการ [SYSTEM_NAME] ให้ลูกค้า ใช้งานได้ทันที หรือปรับชื่อเมนู/ถ้อยคำให้ตรง UI จริงของคุณ

ไฟล์ที่มีให้
- script-1min-th.md — สคริปต์พูด 1 นาที (เกริ่นรวดเร็ว)
- script-3min-th.md — สคริปต์พูด 3 นาที (ภาพรวมพร้อมฟีเจอร์หลัก)
- script-7min-th.md — สคริปต์พูด 6–7 นาที (ลงรายละเอียดเวิร์กโฟลว์)
- demo-runbook.md — ลำดับเดโมคลิกแบบสั้น พร้อมจุดพูด
- slides-outline.md — โครงสไลด์ 8 หน้า พร้อมหัวข้อย่อย
- faq.md — คำถามพบบ่อย + แนวทางตอบ
- checklist.md — เช็กลิสต์ก่อนเดโม/ส่งมอบ

คำแนะนำการใช้งาน
- ค้นหาและแทนที่ [SYSTEM_NAME] และ [CLIENT_NAME] ตามจริง
- หากชื่อเมนูใน UI เป็นภาษาไทย/อังกฤษ ให้ปรับถ้อยคำในสคริปต์ให้ตรงปุ่ม/เมนูจริง
- เวลาเดโม แนะนำ: สคริปต์พูด 3 นาที + เดโมคลิก 3–4 นาที + Q&A 2 นาที
