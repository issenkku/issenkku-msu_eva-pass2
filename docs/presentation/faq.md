# FAQ — [SYSTEM_NAME]

ถาม: ปรับเกณฑ์คะแนนคุณภาพได้ไหม?
ตอบ: ได้ สามารถกำหนดเกณฑ์/สัดส่วนในส่วน Quality Scores และดึงเกณฑ์ตามรายงาน เพื่อให้คะแนนสะท้อนนโยบายองค์กรได้

ถาม: แยกสิทธิ์การเข้าถึงละเอียดแค่ไหน?
ตอบ: จัดการได้ผ่าน Roles & Permissions และมีการควบคุมด้วยเส้นทางและ middleware ทำให้ผู้ใช้เห็นเฉพาะส่วนที่เกี่ยวข้องกับบทบาทของตน

ถาม: รองรับการนำเข้าผู้ใช้จำนวนมากไหม?
ตอบ: รองรับ โดยมีไฟล์เทมเพลตให้ดาวน์โหลด และเมนู Import ช่วยลดเวลาในการตั้งต้นระบบ

ถาม: ตรวจสอบย้อนหลังการเปลี่ยนแปลงได้หรือไม่?
ตอบ: มี Activity Log สำหรับติดตามประวัติการทำงานและการเปลี่ยนแปลงที่สำคัญ สร้างความโปร่งใสและตรวจสอบได้

ถาม: คำนวณคะแนนรวมอย่างไร?
ตอบ: ระบบรองรับคะแนนเชิงปริมาณและเชิงคุณภาพ เมื่อบันทึกคะแนนแล้วจะคำนวณคะแนนรวมอัตโนมัติตามสัดส่วนที่กำหนดไว้ในเกณฑ์

ถาม: ส่งออกข้อมูลได้รูปแบบใดบ้าง?
ตอบ: ส่งออกเป็นไฟล์ Excel ได้ทั้งภาพรวมทั้งระบบ และรายงานรายบุคคล รองรับการใช้งานของฝ่าย HR และผู้บริหาร

ถาม: ปรับแต่งภาษา/คำในระบบได้ไหม?
ตอบ: สามารถปรับคำในหน้าจอและรายงานให้เหมาะกับการใช้งานจริงของ [CLIENT_NAME]
