# คู่มือการใช้งานเบื้องต้น — MSU EVA

ระบบประเมินผลการปฏิบัติงานบุคลากรสาธารณสุข มมส (MSU EVA) รองรับการประเมินแบบหลายบทบาท พร้อมเวิร์กโฟลว์ครบถ้วนตั้งแต่แบบฟอร์ม-การให้คะแนน-การรับรองผล-ออกรายงาน

- URL เข้าระบบ: เปิดเบราว์เซอร์ไปที่หน้า `login` ของระบบ แล้วลงชื่อเข้าใช้ด้วยบัญชีผู้ใช้ที่ได้รับ
- ลืมรหัสผ่าน: ใช้เมนู `forgot-password` เพื่อขออีเมลรีเซ็ตรหัสผ่าน
- ระบบแบ่งหน้าตาตามบทบาท: Admin, Manager, Director, Evaluator, Evaluatee แต่ละบทบาทเห็นเมนูและงานที่เกี่ยวข้องเท่านั้น

## บทบาทผู้ใช้งาน
- Admin (ผู้ดูแลระบบ): จัดการผู้ใช้ บทบาท แผนก ตำแหน่ง เวอร์ชันเกณฑ์ และมอบหมายงาน/รอบประเมิน รวมถึงการออกรายงานรวม
- Manager (หัวหน้างาน/ผู้จัดการ): ตรวจให้คะแนนในส่วนของตน เพิ่มความคิดเห็น และยืนยันส่งต่อ
- Director (ผู้อำนวยการ): ตรวจให้คะแนน/รับรองผลระดับผู้อำนวยการ และสรุปผล
- Evaluator (ผู้ประเมิน): ให้คะแนนตามเกณฑ์ในงานที่ได้รับมอบหมาย
- Evaluatee (ผู้ถูกประเมิน): ทำแบบประเมินของตนเอง (self‑evaluation) และติดตามสถานะ

## เมนูหลักที่พบบ่อย (อ้างอิงเส้นทางในระบบ)
- จัดการผู้ใช้: `users` (เพิ่ม/แก้ไข/ลบ, นำเข้า Excel, ดาวน์โหลดเทมเพลต)
- แผนก: `departments`
- ตำแหน่ง: `positions`
- เกณฑ์/เวอร์ชันแบบประเมิน: `report-version`, หน้าจอปรับเกณฑ์ (Blade) ที่ `criteria-config`
- งานและรอบการประเมิน: `assignment-data`
- หน้าสรุปแดชบอร์ด: `dashboard` (สำหรับ Admin/Manager)
- แดชบอร์ดตามบทบาท:
  - Evaluatee: `evaluatee-dashboard`
  - Evaluator: `evaluator-dashboard`
  - Manager: `manager-dashboard`
  - Director: `director-dashboard`
- ส่งออกไฟล์รายงาน: `export/reports`, `admin/export/reports`, และ `reports/{id}/export`
- โปรไฟล์และรหัสผ่าน: `settings/profile`, `settings/password`, โปรไฟล์สาธารณะ `profile/{uuid}`

## เวิร์กโฟลว์การประเมิน (ภาพรวม)
1) Admin กำหนดเวอร์ชันเกณฑ์ (Criteria) และสร้าง “รายงาน/แบบประเมิน” ของรอบนั้น ๆ
2) Admin มอบหมายงาน (Assignment) ให้ผู้เกี่ยวข้อง: ผู้ถูกประเมิน, ผู้ประเมิน, ผู้จัดการ, ผอ.
3) Evaluatee ทำแบบประเมินของตน → บันทึก/ส่ง
4) Evaluator ให้คะแนนตามรายการเกณฑ์ที่ได้รับ → บันทึกฉบับร่างหรือส่ง
5) Manager ตรวจ/ให้คะแนนและแสดงความคิดเห็น → บันทึกฉบับร่าง (Manager_draft) หรือส่งต่อ/ยืนยัน
6) Director ตรวจ/ให้คะแนนและสรุปผล → ทำเครื่องหมายเสร็จสิ้น (Completed)
7) ผู้เกี่ยวข้องสามารถดูสรุปและ Admin สามารถออกรายงาน Excel ได้

หมายเหตุสถานะที่พบ: Assigned/Draft/Pending/Evaluator_draft/Director_assigned/Director_draft/Manager_assign/Manager_draft/Completed (บางหน้าจอจะแสดงเฉพาะสถานะที่เกี่ยวข้องกับบทบาทนั้น)

## วิธีใช้งานตามบทบาท (ย่อและทำตามหน้าจอจริง)

- Evaluatee (ผู้ถูกประเมิน)
  - เข้า `evaluatee-dashboard` เลือกรอบ/แบบประเมินที่ได้รับ
  - กรอกคะแนน/ข้อมูลตามหัวข้อ (Quantity/Quality) แนบหลักฐาน (ถ้ามี)
  - บันทึกฉบับร่างเพื่อแก้ไขภายหลัง หรือกด “ส่งแบบประเมิน” เพื่อส่งต่อ

- Evaluator (ผู้ประเมิน)
  - เข้า `evaluator-dashboard` → เลือกงาน → หน้า `evaluator/{id}`
  - ให้คะแนนตามเกณฑ์ในหัวข้อ Quantity/Quality ตรงช่องคะแนนที่อนุญาตแก้ไข
  - บันทึกฉบับร่าง หรือส่งคะแนน เมื่อพร้อม

- Manager (หัวหน้างาน)
  - เข้า `manager-dashboard` → เลือกรายการ → หน้า `manager/{id}`
  - ตรวจรายการเกณฑ์ (คอมโพเนนต์รวมจะมีหมวดหลัก/ย่อย สูตรคำนวณ และช่องคะแนน)
  - เพิ่ม “ความคิดเห็น” ประกอบ ถ้าต้องการ
  - ปุ่มบันทึกจะตั้งค่า `status` ได้ เช่น `Manager_draft` (บันทึกฉบับร่าง) หรือ `Completed` (ยืนยัน/ส่งต่อ)
  - เมื่อสถานะไม่เปิดแก้ไข หน้าจะเป็นแบบ Read‑only

- Director (ผู้อำนวยการ)
  - เข้า `director-dashboard` → เลือกรายการ → หน้า `director/{id}`
  - ตรวจ/ให้คะแนนและสรุปผลระดับสุดท้ายก่อนปิดงานเป็น Completed

- Admin (ผู้ดูแลระบบ)
  - ผู้ใช้/สิทธิ์: `users` (เพิ่ม, แก้ไข, ลบ, นำเข้า Excel, กำหนดบทบาท) และ `roles`
  - โครงสร้างเกณฑ์: `report-version` และ `criteria-config` (สร้าง/แก้ไขเวอร์ชัน, รายการเกณฑ์ย่อย)
  - มอบหมายงาน: `assignment-data` (สร้างรอบ, ผูกผู้ประเมิน/ผู้ถูกประเมิน/ผู้จัดการ/ผอ.)
  - แดชบอร์ดรวม: `dashboard` ดูสถานะงานรวม กรอง/ค้นหาได้
  - ส่งออกรายงาน: ใช้ `export/reports` หรือรายงานรายงานเดียว `reports/{id}/export`

## เคล็ดลับการใช้งานฟอร์มให้คะแนน
- ส่วน Quantity/Quality จะจัดกลุ่มเป็น “หมวดหลัก → รายการ → เกณฑ์ย่อย” ให้กรอกเฉพาะช่องที่แก้ไขได้
- บางเกณฑ์มี “สูตร/คำอธิบายคะแนน” แสดงด้านบนของชุดช่องกรอก ควรอ่านก่อนกรอก
- ระบบคำนวณบางคอลัมน์อัตโนมัติ (เช่นค่า D) เมื่อกรอกค่าที่จำเป็นครบ
- ช่อง “ความคิดเห็น” ใช้สื่อสารบริบท/เหตุผล เพื่อช่วยผู้อนุมัติในลำดับถัดไป

## การส่งออกและรายงาน
- รายงานรวมแดชบอร์ด: เข้า `export/reports` (บางสิทธิ์ใช้ `admin/export/reports`)
- รายงานรายชิ้น: `reports/{id}/export`
- ไฟล์ดาวน์โหลดเป็น Excel (รองรับการนำไปสรุปต่อ)

## โปรไฟล์และความปลอดภัย
- แก้ไขโปรไฟล์: `settings/profile`
- เปลี่ยนรหัสผ่าน: `settings/password`
- ลืมรหัสผ่าน: `forgot-password` เพื่อรับอีเมลรีเซ็ต

## การแก้ปัญหาที่พบบ่อย
- เข้าไม่ได้/สิทธิ์ไม่พอ: ตรวจบทบาทกับผู้ดูแลระบบ (Admin)
- ปุ่มบันทึกไม่ขึ้น/แก้ไขไม่ได้: ตรวจสถานะงาน (เช่น ไม่ใช่ Manager_assign/Manager_draft จะเป็น Read‑only)
- คะแนนคำนวณไม่ตรง: ตรวจค่าที่ต้องกรอกครบถ้วนและสูตรเกณฑ์ในหน้าจอ
- ไฟล์ส่งออกเปิดไม่ได้: ลองดาวน์โหลดใหม่หรือเปลี่ยนโปรแกรมเปิด Excel

—
หากต้องการคู่มือแบบละเอียดพร้อมภาพหน้าจอ แจ้งทีมเพื่อจัดทำฉบับเต็มได้

## รายละเอียดแต่ละหน้า (สิ่งที่ควรมี)

- หน้าเข้าสู่ระบบ (`/login`)
  - ช่องกรอกอีเมล/รหัสผ่าน, ปุ่มเข้าสู่ระบบ
  - ลิงก์ลืมรหัสผ่าน (`/forgot-password`)
  - ข้อความแจ้งเตือนเมื่อเข้าสู่ระบบล้มเหลว

- แดชบอร์ดรวม (`/dashboard` สำหรับ Admin/Manager ตามสิทธิ์)
  - ตัวกรอง: ค้นหา, ปี, วันที่เริ่ม-สิ้นสุด, แผนก
  - การ์ดสรุปสถานะ (เช่น Assigned/Draft/Pending/Completed)
  - กราฟสถานะ/กระจายคะแนน (ข้อมูลจาก GraphDataService)
  - ตารางรายการประเมิน: ชื่อรายงาน, ผู้ถูกประเมิน, แผนก, สถานะ, ปุ่มเข้าดู
  - การแบ่งหน้า (pagination)
  - ปุ่มส่งออกสรุป (Export)

- Evaluatee Dashboard (`/evaluatee-dashboard`)
  - รายการแบบประเมินที่ได้รับมอบหมาย พร้อมสถานะและกำหนดส่ง
  - ปุ่ม “ทำแบบประเมิน” ไปหน้า `evaluation/{id}`
  - ตัวกรอง/ค้นหา (ถ้ามี)

- Evaluatee — ทำแบบประเมิน (`/evaluation/{id}`)
  - ส่วนหัวรายงาน: ชื่อรายงาน, เวอร์ชันเกณฑ์, ช่วงเวลา, สถานะ
  - โครงสร้างฟอร์ม: หมวดหลัก → รายการ → เกณฑ์ย่อย แยก Quantity/Quality
  - ช่องกรอกคะแนนที่อนุญาต, คำอธิบาย/สูตรประกอบ, แนบหลักฐาน (ถ้ามี)
  - ปุ่มบันทึกฉบับร่าง/ส่งแบบประเมิน, แจ้งเตือนสำเร็จ/ผิดพลาด

- Evaluator Dashboard (`/evaluator-dashboard`)
  - รายการงานที่ต้องประเมิน พร้อมสถานะและปุ่มเข้า `evaluator/{id}`
  - ตัวกรอง/ค้นหา (ถ้ามี)

- Evaluator — ให้คะแนน (`/evaluator/{id}`)
  - ส่วนหัวรายงานและข้อมูลผู้ถูกประเมิน
  - ฟอร์ม Quantity/Quality ตามโครงสร้างเกณฑ์ (ช่องแก้ไขได้เฉพาะบทบาทนี้)
  - สูตร/คำอธิบายคะแนน (ถ้ามี), หลักฐาน
  - ปุ่มบันทึกฉบับร่าง/ส่งคะแนน

- Manager Dashboard (`/manager-dashboard`)
  - ตัวกรอง: ค้นหา, ปี, วันที่, แผนก (อิง `ManagerController`)
  - การ์ดสรุปสถานะ, กราฟ, ตารางงาน, ปุ่มเข้า `manager/{id}`
  - การแบ่งหน้า

- Manager — ตรวจ/ให้คะแนน (`/manager/{id}`)
  - ส่วนหัว: ชื่อรายงาน, เวอร์ชัน (`$versionName`), ช่วงเวลา (`$startTimeFormatted`–`$endTimeFormatted`)
  - บัตรข้อมูลผู้ประเมิน/ผู้เกี่ยวข้อง (เช่น evaluator/director profile card)
  - ฟอร์มเกณฑ์แบบรวม (Quantity/Quality) พร้อมสูตร/คำอธิบาย
  - กล่อง “ความคิดเห็น” ประกอบการอนุมัติ
  - สถานะฟอร์ม: แก้ไขได้เฉพาะ `Manager_assign`/`Manager_draft` (อื่น ๆ เป็น Read‑only)
  - ปุ่มบันทึก: ตั้งค่า `status` เป็น `Manager_draft` หรือ `Completed` และปุ่มย้อนกลับแดชบอร์ด
  - โมดัลแจ้งผลสำเร็จ/ยืนยัน

- Director Dashboard (`/director-dashboard`)
  - การ์ดสรุป, กราฟ, ตารางงานที่รออนุมัติ, ปุ่มเข้า `director/{id}`

- Director — สรุปผล (`/director/{id}`)
  - ส่วนหัวรายงาน/ผู้ถูกประเมิน
  - ฟอร์มตรวจ/ให้คะแนน (บางช่องอาจเป็นสรุปจากขั้นก่อนหน้า)
  - ปุ่มบันทึก/ปิดงานเป็น `Completed`

- จัดการผู้ใช้ (`/users`)
  - แถบค้นหา/ตัวกรองพื้นฐาน
  - ตารางผู้ใช้: ชื่อ, อีเมล, แผนก, ตำแหน่ง, บทบาท, สถานะ
  - ปุ่ม เพิ่ม/แก้ไข/ลบ ผู้ใช้
  - ปุ่มนำเข้าไฟล์ Excel + โมดัลอัปโหลด + ปุ่มดาวน์โหลดเทมเพลต

- จัดการบทบาท/สิทธิ์ (`/roles`)
  - รายการบทบาท, ฟอร์มตั้งค่าสิทธิ์ (permissions)
  - ผูกผู้ใช้กับบทบาท (ถ้ามีในหน้า)

- แผนก (`/departments`) และ ตำแหน่ง (`/positions`)
  - ตารางรายการ, ฟอร์มเพิ่ม/แก้ไข/ลบ, ปุ่มดำเนินการ

- เกณฑ์/เวอร์ชันแบบประเมิน
  - API/CRUD: `report-version` (index/show/create/update/delete)
  - UI ปรับเกณฑ์ (Blade): `criteria-config` (index/create/edit/evaluators)
  - ฟิลด์ควรมี: ชื่อเวอร์ชัน, คำอธิบาย, โครงสร้างหมวด/รายการ/เกณฑ์ย่อย, น้ำหนัก/สูตร, การผูกผู้ประเมิน

- งานและรอบการประเมิน (`/assignment-data`)
  - ตารางรอบ: ชื่อรอบ, ช่วงเวลา, เวอร์ชันเกณฑ์, แผนกที่เกี่ยวข้อง
  - ฟอร์มมอบหมาย: ผู้ถูกประเมิน, ผู้ประเมิน, ผู้จัดการ, ผอ., ความสัมพันธ์กับรายงาน

- คะแนนเชิงคุณภาพ/ปริมาณ (Quality/Quantity Scores)
  - หน้า `quality-scores` (index/create/edit/show): ตารางรายการ, ฟอร์มคะแนนคุณภาพ
  - ในหน้าประเมิน: ช่องคะแนนย่อย A/B/C/D (ตามสูตร), แสดงค่าอัตโนมัติที่คำนวณได้

- ส่งออก/รายงาน (`/export/reports`, `/admin/export/reports`, `/reports/{id}/export`)
  - ปุ่มดาวน์โหลด Excel: รายงานรวม และรายงานเดี่ยว
  - ตัวกรองก่อนส่งออก (ถ้ามี): ปี, แผนก, สถานะ

- โปรไฟล์และรหัสผ่าน (`/settings/profile`, `/settings/password`)
  - โปรไฟล์: รูป/ชื่อ/อีเมล/แผนก/ตำแหน่ง/ลิงก์โปรไฟล์สาธารณะ
  - รหัสผ่าน: ฟอร์มเปลี่ยนรหัสผ่านพร้อมยืนยัน
  - ลิงก์ขอรีเซ็ตรหัสผ่าน: `/forgot-password`

- บันทึกกิจกรรม (Activity Log)
  - ตารางเหตุการณ์: เวลา, ผู้กระทำ, รายการที่เกี่ยวข้อง, รายละเอียดการเปลี่ยนแปลง
  - ตัวกรองวันที่/ประเภทเหตุการณ์
