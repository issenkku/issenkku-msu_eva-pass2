# อัพเดท Path และข้อมูลสำหรับ Endpoints

## 1. CRUD Operations

### 1.1 สร้าง Report (POST /reports)
**Path:** `POST /reports`
**Body:**
```json
{
  "report_data_id": 1,
  "report_code": "RPT-2023-001",
  "status": "Draft"
}
```

### 1.2 แสดงข้อมูล Report (GET /reports/{reportId})
**Path:** `GET /reports/1`

### 1.3 อัพเดท Report (PUT /reports/{reportId})
**Path:** `PUT /reports/1`
**Body:**
```json
{
  "report_data_id": 2,
  "report_code": "RPT-2023-002",
  "status": "Completed"
}
```
**หมายเหตุ:** status ต้องเป็น `Completed` (ตัวใหญ่ตัวแรก) ไม่ใช่ `completed`

### 1.4 ลบ Report (DELETE /reports/{reportId})
**Path:** `DELETE /reports/1`

## 4. Evidence Answers Operations

### 4.1 เพิ่ม Evidence Answers (POST /reports/{reportId}/evidence-answers)
**Path:** `POST /reports/1/evidence-answers`
**Body:**
```json
{
  "evidence_list": [
    {
      "evaluation_list_id": 1,
      "link": "https://example.com/evidence1"
    },
    {
      "evaluation_list_id": 2,
      "link": "https://example.com/evidence2"
    },
    {
      "evaluation_list_id": 3,
      "link": null
    }
  ]
}
```

### 4.2 อัพเดท Evidence Answers (PUT /reports/{reportId}/evidence-answers)
**Path:** `PUT /reports/1/evidence-answers`
**Body:**
```json
{
    "evidence_list": [
        {
            "evaluation_list_id": 3,
            "link_old": "sss.com",
            "link_new": "test.com"
        }
    ]
}
```
